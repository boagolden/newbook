# 集卡抽奖 v1.0 小程序骨架

这是从当前 Web 版页面抽出来的微信小程序基础结构。

## 目录
- `app.js`
- `app.json`
- `app.wxss`
- `pages/index/index.js`
- `pages/index/index.wxml`
- `pages/index/index.wxss`

## 预览
1. 用微信开发者工具打开 `C:\code\newbook\miniapp`
2. 确认基础库版本较新
3. 直接预览首页

## 当前能力
- 手机端海报式首屏
- 6 张活动卡片
- 点击按钮后模拟次数、进度、积分变化
- 底部 toast 反馈
